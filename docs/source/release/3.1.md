# Version 3.1

## New

- SSH and FTP crawler jobs use `fs.ssh.*` / `fs.ftp.*` with the same field names as the REST
  `_document` payload (`hostname`, `port`, `username`, `password`, `pem_path`). The crawl root
  stays `fs.url`. REST calls can omit connection fields when they are set on the job.
  See {ref}`ssh-settings` and {ref}`ftp-settings`. Thanks to dadoonet.

## Deprecated

- The top-level `server.*` settings (`hostname`, `port`, `username`, `password`, `pem_path`) are
  deprecated and will be removed in a future version. Use `fs.ssh.*` or `fs.ftp.*` instead (same
  field names as the REST `_document` payload). When a deprecated field is used, FSCrawler logs a
  WARN with the replacement key, for example:

  `Setting server.hostname is deprecated and will be removed in a future version. Please use fs.ssh.hostname: "mynode.mydomain.com" instead.`

  If both the new and the old keys are set, the new value wins and the WARN says the old value is
  ignored. Password WARNs never echo the password. Thanks to dadoonet.

Thanks to `@dadoonet` and all the contributors for this release!
